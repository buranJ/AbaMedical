# SEO migration checklist

- [x] Инвентаризированы основной и товарный sitemap старого сайта
- [x] Все старые статические URL сохранены либо имеют 301
- [x] Все 100 Tilda product URL имеют шаблонный 301
- [x] Unique title/description/canonical для индексируемых шаблонов
- [x] Один H1 и логичная H2/H3-иерархия
- [x] Organization, WebSite, BreadcrumbList, Product, Article и FAQPage без фиктивных rating/price
- [x] Динамические `sitemap.xml` и `robots.txt`
- [x] Semantically correct breadcrumbs и внутренние ссылки
- [x] Осмысленные alt, локальные ключевые изображения
- [x] Custom 404 с маршрутами в каталог и на главную
- [x] Единый NAP и LocalBusiness/Organization данные
- [x] HTTPS canonical без trailing slash (кроме root)
- [ ] После переключения домена отправить новый sitemap в Google Search Console и Яндекс Вебмастер
- [ ] Сопоставить реальные 404/redirect hits по логам через 7, 30 и 90 дней
- [ ] Подтвердить ownership и verification IDs через environment variables
